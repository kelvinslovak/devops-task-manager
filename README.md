# DevOps Task Manager

Projeto prático para aprendizado de DevOps e Cloud Native.

## Tecnologias
- Python / FastAPI
- Docker / Docker Compose
- AWS / Terraform
- Kubernetes / EKS
- GitHub Actions / Argo CD
- Prometheus / Grafana

## Objetivo
Construir uma API de gerenciamento de tarefas
com infraestrutura automatizada, CI/CD,
escalabilidade e observabilidade.
